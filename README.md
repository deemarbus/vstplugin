# QuadTable

QuadTable is an early JUCE/C++ VST3 instrument prototype for a four-oscillator wavetable synth.

## Current prototype

- JUCE 8/CMake project that builds a VST3 and standalone instrument.
- 16-voice polyphonic MIDI synth engine.
- Four wavetable oscillators per voice.
- Per-oscillator level, pan, coarse tune, fine tune, and wavetable position parameters.
- Amp ADSR and filter ADSR.
- One state-variable low-pass filter per voice.
- Initial modulation-matrix data model for adding flexible routing in later milestones.
- Generic JUCE parameter editor for fast iteration.

## Build

The default configure path is network-free, so it works even when the environment cannot clone JUCE from GitHub. Without JUCE it builds `QuadTableCore` and a smoke-test executable for the wavetable oscillator core:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build --output-on-failure
```

To build the real VST3/Standalone plugin target, provide a local JUCE checkout:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DJUCE_SOURCE_DIR=/path/to/JUCE
cmake --build build --config Release
```

If your network allows GitHub access, CMake can fetch JUCE instead:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DQUADTABLE_FETCH_JUCE=ON
cmake --build build --config Release
```

The VST3 target is generated by JUCE under the CMake build directory when JUCE is available.

## Roadmap

1. Replace the generic editor with a custom synth UI.
2. Expose modulation matrix slots as automatable parameters.
3. Add more filter modes and dual-filter routing.
4. Add unison, warp modes, oscillator sync, and wavetable import.
5. Add preset management and macro controls.
